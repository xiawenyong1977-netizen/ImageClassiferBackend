# 生产环境清理指南

## 📋 概述

生产环境部署完成后，建议清理不必要的文件，保持目录整洁和安全。

## 🗑️ 可以删除的文件

### 1. Example 配置文件（推荐删除）

**文件**：
- `/opt/ICBackend/env.example`
- `/opt/ICBackend/env.example.secrets`

**删除原因**：
- ✅ 配置已经完成，不需要模板文件
- ✅ 减少暴露的信息
- ✅ 保持目录整洁
- ✅ 符合安全最佳实践

**删除命令**：
```bash
cd /opt/ICBackend
rm -f env.example env.example.secrets
```

**删除后影响**：
- ✅ **不影响部署**：版本化部署脚本会将 example 文件复制到版本目录
- ✅ **不影响运行**：实际配置文件（`.env` 和 `.env.secrets`）不受影响
- ✅ **不影响回滚**：回滚时会使用版本目录中的 example 文件

### 2. 其他可选清理项

#### README.md（如果存在）
```bash
# 如果不需要文档，可以删除
rm -f /opt/ICBackend/README.md
```

#### 临时文件
```bash
# 清理临时文件（如果有）
find /opt/ICBackend -name "*.tmp" -delete
find /opt/ICBackend -name "*.log" -delete  # 注意：保留应用日志
```

## ✅ 必须保留的文件

### 配置文件
- ✅ `.env` - 应用配置（必须保留）
- ✅ `.env.secrets` - 敏感配置（必须保留）

### 目录结构
- ✅ `versions/` - 版本目录（必须保留）
- ✅ `current` - 当前版本符号链接（必须保留）
- ✅ `venv/` - 共享虚拟环境（必须保留）
- ✅ `prompts/` - 提示词目录（如果应用需要）

## 📝 清理检查清单

部署完成后，检查以下项目：

- [ ] 删除根目录的 `env.example`
- [ ] 删除根目录的 `env.example.secrets`
- [ ] 确认 `.env` 文件存在且配置正确
- [ ] 确认 `.env.secrets` 文件存在且权限为 600
- [ ] 确认 `current` 符号链接指向正确的版本
- [ ] 确认服务正常运行

## ⚠️ 注意事项

1. **不要删除版本目录中的 example 文件**
   - 版本目录（`versions/xxx/`）中的 example 文件应该保留
   - 这些文件用于：
     - 查看历史版本的配置模板
     - 回滚时参考配置

2. **备份配置文件**
   - 删除前建议备份配置文件：
   ```bash
   cp /opt/ICBackend/.env /opt/ICBackend/.env.backup.$(date +%Y%m%d)
   cp /opt/ICBackend/.env.secrets /opt/ICBackend/.env.secrets.backup.$(date +%Y%m%d)
   ```

3. **文件权限**
   - 确保 `.env.secrets` 权限为 600：
   ```bash
   chmod 600 /opt/ICBackend/.env.secrets
   ```

## 🔄 自动清理脚本

可以创建一个清理脚本：

```bash
#!/bin/bash
# 生产环境清理脚本

DEPLOY_DIR="/opt/ICBackend"

echo "开始清理生产环境..."

cd "$DEPLOY_DIR" || exit 1

# 备份配置文件
echo "备份配置文件..."
cp .env .env.backup.$(date +%Y%m%d) 2>/dev/null || true
cp .env.secrets .env.secrets.backup.$(date +%Y%m%d) 2>/dev/null || true

# 删除 example 文件
echo "删除 example 文件..."
rm -f env.example env.example.secrets

# 检查文件权限
echo "检查文件权限..."
chmod 600 .env.secrets 2>/dev/null || true

echo "清理完成！"
echo ""
echo "当前目录内容："
ls -la "$DEPLOY_DIR" | grep -E "^(-|d)" | grep -v "^d.*versions"
```
