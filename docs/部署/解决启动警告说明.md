# 解决启动警告说明

## 问题描述

服务启动时会出现以下警告：

```
mkdir -p failed for path /root/.config/matplotlib: [Errno 30] Read-only file system
Matplotlib created a temporary cache directory at /tmp/matplotlib-...
WARNING ⚠️ user config directory '/root/.config/Ultralytics' is not writeable, defaulting to...
```

## 原因分析

1. **systemd 安全设置**：服务配置中设置了 `ProtectHome=true`，将 `/root` 目录设为只读
2. **库的默认行为**：
   - `matplotlib` 库默认在 `~/.config/matplotlib` 创建配置文件
   - `ultralytics` 库默认在 `~/.config/Ultralytics` 创建配置文件
3. **自动降级**：当无法写入时，这些库会自动使用临时目录（如 `/tmp/`）

## 影响

- ✅ **不影响功能**：库会自动处理，使用临时目录
- ⚠️ **警告信息**：启动日志中会有警告信息
- ⚠️ **配置丢失**：临时目录在重启后可能被清理

## 解决方案

### 方案1：设置环境变量（推荐）

在 systemd 服务文件中添加环境变量，指定库的配置目录：

```ini
[Service]
# ... 其他配置 ...
Environment="MPLCONFIGDIR=/tmp/matplotlib"
Environment="ULTRALYTICS_HOME=/tmp/ultralytics"
```

**优点**：
- 消除警告信息
- 明确指定配置目录
- 不影响安全性

**缺点**：
- 配置目录在重启后可能被清理（但通常不影响功能）

### 方案2：使用持久化目录

如果需要持久化配置，可以使用应用目录下的子目录：

```ini
[Service]
# ... 其他配置 ...
Environment="MPLCONFIGDIR=/opt/ICBackend/.cache/matplotlib"
Environment="ULTRALYTICS_HOME=/opt/ICBackend/.cache/ultralytics"
```

然后确保目录存在且可写：

```bash
mkdir -p /opt/ICBackend/.cache/{matplotlib,ultralytics}
chown -R root:root /opt/ICBackend/.cache
```

### 方案3：修改 systemd 配置（不推荐）

移除 `ProtectHome=true` 或添加 `ReadWritePaths`：

```ini
[Service]
# 不推荐：降低安全性
ProtectHome=false

# 或添加可写路径
ReadWritePaths=/root/.config
```

**不推荐原因**：
- 降低系统安全性
- 违反最小权限原则

## 实施步骤

### 1. 修改服务文件

编辑 `/etc/systemd/system/image-classifier.service`：

```bash
sudo nano /etc/systemd/system/image-classifier.service
```

添加环境变量：

```ini
Environment="MPLCONFIGDIR=/tmp/matplotlib"
Environment="ULTRALYTICS_HOME=/tmp/ultralytics"
```

### 2. 重新加载并重启服务

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 重启服务
sudo systemctl restart image-classifier

# 查看日志确认警告消失
sudo journalctl -u image-classifier -f
```

### 3. 验证

启动后应该不再看到相关警告信息。

## 环境变量说明

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `MPLCONFIGDIR` | Matplotlib 配置目录 | `~/.config/matplotlib` |
| `ULTRALYTICS_HOME` | Ultralytics 配置目录 | `~/.config/Ultralytics` |

## 注意事项

1. **临时目录清理**：`/tmp` 目录在系统重启后可能被清理，但不影响库的正常使用
2. **多进程环境**：如果使用 Gunicorn 多进程，每个进程都会创建自己的配置目录
3. **权限问题**：确保指定的目录对运行用户可写
