# 试用模式接口返回验证

## 配置项

当 `ALLOW_IMAGE_EDIT_WITHOUT_OPENID=true` 时，以下接口的行为：

## 1. 额度查询接口 `/api/v1/user/credits`

### 场景1：有 client_id，但没有绑定 openid

**请求：**
```bash
GET /api/v1/user/credits?client_id=test-client-id-123
```

**预期返回（配置项开启）：**
```json
{
  "success": true,
  "total_credits": null,        // ✅ 试用模式无额度限制
  "used_credits": 0,            // ✅ 已使用额度为0
  "remaining_credits": null,    // ✅ 试用模式无额度限制
  "is_followed": false,         // ✅ 未关注公众号
  "is_member": false,           // ✅ 不是会员
  "member_expire_at": null,     // ✅ 无会员过期时间
  "is_trial_mode": true         // ✅ 标识为试用模式
}
```

**预期返回（配置项关闭）：**
```json
{
  "detail": "用户未关注公众号"
}
```
状态码：404

### 场景2：既没有 client_id 也没有 openid

**请求：**
```bash
GET /api/v1/user/credits
```

**预期返回（配置项开启）：**
```json
{
  "success": true,
  "total_credits": null,
  "used_credits": 0,
  "remaining_credits": null,
  "is_followed": false,
  "is_member": false,
  "member_expire_at": null,
  "is_trial_mode": true
}
```

**预期返回（配置项关闭）：**
```json
{
  "detail": "缺少client_id或openid参数"
}
```
状态码：400

### 场景3：有 openid（正常用户）

**请求：**
```bash

Headers: X-WeChat-OpenID: oKbfi1wlkjqhkaHYIYKUxwJe66P8
```

**预期返回：**
```json
{

  "total_credits": 10,
  "used_credits": 5,
  "remaining_credits": 5,
  "is_followed": true,          // ✅ 已关注公众号
```

```json
}
```

## 3. 图像编辑接口 `/api/v2/image-edit/batch`

### 场景1：没有 openid，配置项开启

**请求：**
```bash
POST /api/v2/image-edit/batch
Headers: X-User-ID: test-client-id-123
Form Data:
  - images: [图片文件]
  - image_metadata: {"prompt": "美化图片", "items": [...]}
```

**预期行为：**
- ✅ 允许提交任务
- ✅ 不检查额度
- ✅ 任务完成后不扣减额度
- ✅ 返回 task_id

**响应：**
```json
{
  "error_type": "SUCCESS",
  "task_id": "task_xxx",
  "total_images": 1,
  "request_id": "batch_edit_xxx"
}
```

### 场景2：没有 openid，配置项关闭

**请求：**
```bash
POST /api/v2/image-edit/batch
Headers: X-User-ID: test-client-id-123
Form Data:
  - images: [图片文件]
  - image_metadata: {"prompt": "美化图片", "items": [...]}
```

**预期行为：**
- ❌ 拒绝请求
- ❌ 返回错误信息

**响应：**
```json
{
  "detail": "需要关注公众号才能使用修图功能，请先关注公众号"
}
```
状态码：400

**请求：**

## 注意事项

1. **配置项位置**：`.env` 或 `.env.secrets` 文件中设置 `ALLOW_IMAGE_EDIT_WITHOUT_OPENID=true`
2. **重启服务**：修改配置后需要重启服务才能生效
3. **前端适配**：前端需要根据 `is_trial_mode` 字段显示不同的UI
4. **额度显示**：试用模式下，`total_credits` 和 `remaining_credits` 为 `null`，前端应显示"无限制"或"试用模式"
