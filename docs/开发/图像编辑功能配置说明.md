# 图像编辑功能配置说明

## 配置项：ALLOW_IMAGE_EDIT_WITHOUT_OPENID

### 功能说明
控制是否允许未关注公众号的用户使用修图功能。

### 配置方式

在 `.env` 或 `.env.secrets` 文件中添加：

```bash
# 允许未关注公众号的用户使用修图功能
ALLOW_IMAGE_EDIT_WITHOUT_OPENID=true

# 或禁止未关注公众号的用户使用修图功能（默认）
ALLOW_IMAGE_EDIT_WITHOUT_OPENID=false
```

### 行为说明

#### 当 `ALLOW_IMAGE_EDIT_WITHOUT_OPENID=false`（默认值）
- ✅ 用户必须关注公众号（有 `openid`）才能使用修图功能
- ✅ 会检查用户的正式额度
- ✅ 任务完成时会扣减用户的正式额度
- ❌ 未关注公众号的用户会被拒绝

#### 当 `ALLOW_IMAGE_EDIT_WITHOUT_OPENID=true`
- ✅ 用户无需关注公众号即可使用修图功能
- ✅ 不检查额度（不要求有 `openid`）
- ✅ 任务完成时不扣减任何额度
- ⚠️ **注意**：此模式下无法控制使用量，可能被滥用

### 使用场景

1. **开发/测试环境**：
   - 设置为 `true`，方便测试，无需关注公众号

2. **生产环境（推荐）**：
   - 设置为 `false`，要求用户关注公众号，便于用户管理和额度控制

3. **推广活动**：
   - 临时设置为 `true`，允许新用户免费试用
   - 活动结束后改回 `false`

### 技术实现

- 配置项位置：`app/config.py`
- 实现位置：`app/api/image_edit_v2.py`
- 检查时机：提交任务时（`/api/v2/image-edit/batch`）
- 额度扣减：任务完成时（仅在 `openid` 存在时扣减）

### 注意事项

1. **安全性**：开启此配置项后，无法控制使用量，可能被恶意用户滥用
2. **成本控制**：建议在生产环境关闭此配置项，或结合其他限制措施（如 IP 限制、频率限制）
3. **用户体验**：开启后，用户无需关注公众号即可使用，但无法享受会员权益和额度管理
