# 查看日志说明

## 📋 日志文件位置

### 1. 应用日志（应用运行日志）
```bash
# 查看应用日志
ssh root@app "tail -f /var/log/image-classifier/app.log"

# 查看最近100行
ssh root@app "tail -n 100 /var/log/image-classifier/app.log"

# 查看包含"统一请求日志"的记录
ssh root@app "grep '统一请求日志' /var/log/image-classifier/app.log | tail -20"

# 查看错误日志
ssh root@app "grep -i error /var/log/image-classifier/app.log | tail -20"
```

### 2. Gunicorn 访问日志（HTTP请求日志）
```bash
# 实时查看访问日志
ssh root@app "tail -f /var/log/image-classifier/access.log"

# 查看最近的请求
ssh root@app "tail -n 50 /var/log/image-classifier/access.log"
```

### 3. Gunicorn 错误日志
```bash
# 查看错误日志
ssh root@app "tail -f /var/log/image-classifier/error.log"

# 查看最近的错误
ssh root@app "tail -n 50 /var/log/image-classifier/error.log"
```

## 🗄️ 数据库统一日志表

### 查看统一日志表数据
```bash
ssh root@app "mysql -u root -p image_classifier -e \"SELECT * FROM unified_request_log ORDER BY created_at DESC LIMIT 20;\""
```

### 查看今日统计（验证数据是否正确记录）
```bash
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT 
    request_type,
    COUNT(*) as count,
    SUM(total_images) as total_images,
    SUM(cached_count) as cached_count,
    SUM(llm_count) as llm_count,
    SUM(local_count) as local_count
FROM unified_request_log
WHERE created_date = CURDATE()
GROUP BY request_type;
\""
```

### 查看今日独立IP和用户数
```bash
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT 
    COUNT(DISTINCT ip_address) as unique_ips,
    COUNT(DISTINCT CASE WHEN openid IS NOT NULL THEN openid WHEN client_id IS NOT NULL THEN client_id ELSE NULL END) as unique_users
FROM unified_request_log
WHERE created_date = CURDATE();
\""
```

## 🔍 快速检查脚本

创建一个快速检查脚本：

```bash
#!/bin/bash
# 快速检查日志和统计

echo "=== 应用日志（最近10行）==="
ssh root@app "tail -n 10 /var/log/image-classifier/app.log"

echo ""
echo "=== 今日统一日志统计 ==="
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT 
    request_type,
    COUNT(*) as requests,
    SUM(total_images) as total_images,
    SUM(cached_count) as cached,
    SUM(llm_count) as llm,
    SUM(local_count) as local
FROM unified_request_log
WHERE created_date = CURDATE()
GROUP BY request_type;
\""

echo ""
echo "=== 最近5条统一日志 ==="
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT 
    request_id,
    request_type,
    ip_address,
    total_images,
    cached_count,
    llm_count,
    local_count,
    created_at
FROM unified_request_log
ORDER BY created_at DESC
LIMIT 5;
\""
```

## ✅ 验证统一日志是否正常工作

### 1. 检查是否有新记录
```bash
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT COUNT(*) as total_records,
       MAX(created_at) as latest_record
FROM unified_request_log;
\""
```

### 2. 检查各类型请求是否都有记录
```bash
ssh root@app "mysql -u root -p image_classifier -e \"
SELECT request_type, COUNT(*) as count
FROM unified_request_log
WHERE created_date = CURDATE()
GROUP BY request_type;
\""
```

### 3. 检查是否有错误记录
```bash
ssh root@app "grep -i '统一请求日志失败\|记录统一请求日志失败' /var/log/image-classifier/app.log | tail -10"
```

## 📊 实时监控

```bash
# 查看统计接口的调用情况
ssh root@app "tail -f /var/log/image-classifier/access.log | grep '/api/v1/stats/today'"
```

## 🚨 常见问题排查

### 1. 如果统一日志表没有数据
- 检查 `ENABLE_REQUEST_LOG` 配置是否为 `True`
- 检查应用日志是否有错误信息
- 检查数据库连接是否正常

### 2. 如果统计数据不准确
- 检查 `created_date` 字段是否正确生成
- 检查时区设置是否正确
- 检查是否有旧数据干扰

### 3. 如果日志文件不存在
```bash
# 检查日志目录是否存在
ssh root@app "ls -la /var/log/image-classifier/"

# 如果不存在，创建目录
ssh root@app "mkdir -p /var/log/image-classifier && chown -R root:root /var/log/image-classifier"
```
