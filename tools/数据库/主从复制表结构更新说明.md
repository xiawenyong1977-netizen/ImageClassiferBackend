# 主从复制环境下表结构更新说明

## 概述

在主从复制环境下，当需要更新表结构（如添加字段）时，需要特别注意同步问题。

## 更新方式

### 方式1：在主库执行（推荐）

**原理**：DDL语句（如 `ALTER TABLE`）会通过 binlog 自动同步到从库。

**步骤**：

1. **在主库执行迁移脚本**
```bash
# 在主库（App服务器）执行
mysql -u root -p image_classifier < tools/数据库/add_ip_address_to_image_edit_tasks.sql
```

2. **检查从库同步状态**
```bash
# 在从库（Web服务器）检查
ssh root@web "mysql -u root -p -e 'SHOW SLAVE STATUS\G' | grep -E 'Slave_IO_Running|Slave_SQL_Running|Seconds_Behind_Master|Last_Error'"
```

3. **验证从库表结构**
```bash
# 在从库验证字段是否已添加
ssh root@web "mysql -u root -p image_classifier -e 'DESC image_edit_tasks;' | grep ip_address"
```

### 方式2：如果主从同步失败，在从库手动执行

**适用场景**：
- 主从复制已停止
- 从库同步报错
- 需要立即更新从库表结构

**步骤**：

1. **停止从库同步**
```bash
ssh root@web "mysql -u root -p -e 'STOP SLAVE;'"
```

2. **在从库执行迁移脚本**
```bash
# 将脚本复制到从库
scp tools/数据库/add_ip_address_to_image_edit_tasks.sql root@web:/tmp/

# 在从库执行
ssh root@web "mysql -u root -p image_classifier < /tmp/add_ip_address_to_image_edit_tasks.sql"
```

3. **重新启动从库同步**
```bash
ssh root@web "mysql -u root -p -e 'START SLAVE;'"
```

4. **检查从库状态**
```bash
ssh root@web "mysql -u root -p -e 'SHOW SLAVE STATUS\G' | grep -E 'Slave_IO_Running|Slave_SQL_Running|Seconds_Behind_Master'"
```

## 检查命令

### 检查主库表结构
```bash
mysql -u root -p image_classifier -e 'DESC image_edit_tasks;'
```

### 检查从库表结构
```bash
ssh root@web "mysql -u root -p image_classifier -e 'DESC image_edit_tasks;'"
```

### 检查从库同步状态
```bash
ssh root@web "mysql -u root -p -e 'SHOW SLAVE STATUS\G'"
```

**关键字段说明**：
- `Slave_IO_Running`: 应该是 `Yes`（IO线程运行中）
- `Slave_SQL_Running`: 应该是 `Yes`（SQL线程运行中）
- `Seconds_Behind_Master`: 延迟秒数（应该接近0）
- `Last_Error`: 应该是空的（如果有错误会显示在这里）

## 注意事项

1. **从库只读模式**：从库通常设置为只读（`read-only=1`），但 `ALTER TABLE` 等DDL语句在从库的SQL线程中会以超级用户权限执行，不受只读限制。

2. **同步延迟**：如果主从复制有延迟，从库的表结构更新可能会稍晚于主库。

3. **数据一致性**：确保主从库的表结构一致，否则可能导致查询错误。

4. **备份建议**：在执行表结构变更前，建议先备份数据库。

## 故障排查

### 问题1：从库同步报错 "Table doesn't exist"
**原因**：从库表结构未同步
**解决**：在从库手动执行表结构更新脚本

### 问题2：从库同步报错 "Duplicate column name"
**原因**：字段已存在
**解决**：检查表结构，如果字段已存在则无需执行

### 问题3：从库同步延迟很大
**原因**：网络问题或从库性能不足
**解决**：
1. 检查网络连接
2. 检查从库性能
3. 考虑在从库手动执行以加快更新速度
