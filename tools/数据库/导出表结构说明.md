# 从服务器导出数据库表结构

## 方法1：直接SSH执行命令（推荐）

### Linux/Mac

```bash
# 连接到服务器并导出表结构
ssh root@app "mysqldump -u classifier -p'Classifier@2024' \
    --no-data \
    --skip-triggers \
    --skip-routines \
    --skip-events \
    --single-transaction \
    --routines=false \
    --databases image_classifier" \
    | grep -v "Warning: Using a password" \
    | sed 's/image_classifier/image_classifier_test/g' \
    > tests/setup_test_db.sql
```

### Windows PowerShell

```powershell
# 连接到服务器并导出表结构
ssh root@app "mysqldump -u classifier -p'Classifier@2024' --no-data --skip-triggers --skip-routines --skip-events --single-transaction --routines=false --databases image_classifier" | Where-Object { $_ -notmatch "Warning" } | ForEach-Object { $_ -replace 'image_classifier', 'image_classifier_test' } | Out-File -FilePath tests\setup_test_db.sql -Encoding UTF8
```

## 方法3：手动步骤

1. **SSH连接到服务器**
   ```bash
   ssh root@app
   ```

2. **在服务器上执行导出命令**
   ```bash
   mysqldump -u classifier -p'Classifier@2024' \
       --no-data \
       --skip-triggers \
       --skip-routines \
       --skip-events \
       --single-transaction \
       --routines=false \
       --databases image_classifier > /tmp/schema.sql
   ```

3. **下载文件到本地**
   ```bash
   scp root@app:/tmp/schema.sql tests/setup_test_db.sql
   ```

4. **修改数据库名**
   ```bash
   # Linux/Mac
   sed -i 's/image_classifier/image_classifier_test/g' tests/setup_test_db.sql
   
   # Windows PowerShell
   (Get-Content tests\setup_test_db.sql) -replace 'image_classifier', 'image_classifier_test' | Set-Content tests\setup_test_db.sql
   ```

## 注意事项

1. **密码安全**：如果密码包含特殊字符，可能需要转义或使用配置文件
2. **数据库名替换**：确保将所有 `image_classifier` 替换为 `image_classifier_test`
3. **添加测试数据**：导出后需要手动添加测试数据（如测试城市数据）
4. **过滤警告**：mysqldump 会输出警告信息，需要过滤掉

## 导出后的处理

导出后，需要在文件开头添加：

```sql
-- 创建测试数据库（如果不存在）
CREATE DATABASE IF NOT EXISTS image_classifier_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE image_classifier_test;
```

并在文件末尾添加测试数据插入语句。
