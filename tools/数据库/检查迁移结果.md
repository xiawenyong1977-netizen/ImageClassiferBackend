# 检查迁移结果

## 方式1：使用 SQL 脚本检查（推荐）

在主库执行以下命令：

```bash
mysql -u root -p image_classifier < tools/数据库/check_migration_result.sql
```

## 方式2：手动执行 SQL 检查

连接到主库后，执行以下 SQL：

```sql
USE image_classifier;

-- 检查字段是否存在
SELECT 
    CASE 
        WHEN COUNT(*) > 0 THEN '✅ ip_address 字段已存在'
        ELSE '❌ ip_address 字段不存在'
    END AS '字段检查'
FROM information_schema.COLUMNS
WHERE TABLE_SCHEMA = 'image_classifier'
  AND TABLE_NAME = 'image_edit_tasks'
  AND COLUMN_NAME = 'ip_address';

-- 检查索引是否存在
SELECT 
    CASE 
        WHEN COUNT(*) > 0 THEN '✅ idx_ip_address 索引已存在'
        ELSE '❌ idx_ip_address 索引不存在'
    END AS '索引检查'
FROM information_schema.STATISTICS
WHERE TABLE_SCHEMA = 'image_classifier'
  AND TABLE_NAME = 'image_edit_tasks'
  AND INDEX_NAME = 'idx_ip_address';

-- 显示表结构
DESC image_edit_tasks;
```

## 方式3：简单检查命令

```bash
# 检查字段
mysql -u root -p image_classifier -e "SHOW COLUMNS FROM image_edit_tasks LIKE 'ip_address';"

# 检查索引
mysql -u root -p image_classifier -e "SHOW INDEX FROM image_edit_tasks WHERE Key_name = 'idx_ip_address';"
```

## 预期结果

如果迁移成功，应该看到：

1. **字段检查**：`✅ ip_address 字段已存在`
   - 类型：`varchar(45)`
   - 允许NULL：`YES`
   - 注释：`客户端IP地址`

2. **索引检查**：`✅ idx_ip_address 索引已存在`
   - 列名：`ip_address`
   - 非唯一：`1`

3. **表结构**：在 `DESC image_edit_tasks` 的输出中，应该能看到 `ip_address` 字段位于 `user_id` 之后。

## 检查从库同步

如果配置了主从复制，可以检查从库是否已同步：

```bash
# 检查从库字段
ssh root@web "mysql -u root -p image_classifier -e \"SHOW COLUMNS FROM image_edit_tasks LIKE 'ip_address';\""

# 检查从库同步状态
ssh root@web "mysql -u root -p -e 'SHOW SLAVE STATUS\G' | grep -E 'Slave_IO_Running|Slave_SQL_Running|Seconds_Behind_Master'"
```

## 如果检查失败

如果字段或索引不存在，请执行迁移脚本：

```bash
mysql -u root -p image_classifier < tools/数据库/add_ip_address_to_image_edit_tasks.sql
```
